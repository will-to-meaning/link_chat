# Design

## 控制台的第一眼

打开后台，先看到完整的实况画面。左边是一条窄轨，右边是一体化显示屏。顶部留给一眼读完的态势，中间留给活动本身，底边留给回看和调整。侧轨展开时像把面板从屏幕边缘拉出，收回后可以继续追踪同一个频道或玩家。

```text
┌──────┬──────────────────────────────────────────────────────┐
│ 菜单 │ 实况   连接状态  在线用户  活跃频道  近一分钟活动       │
│ 实况 ├──────────────────────────────────────────────────────┤
│      │                                        [模拟测试]    │
│ 内容 │               三维场景和选中对象                       │
│ 管理 │                                                      │
│      │                                                      │
│ 账户 │  场景控制          活动曲线             活动日志        │
└──────┴──────────────────────────────────────────────────────┘
```

| 入口 | 功能 | 展开后的行为 |
|---|---|---|
| 实况 | 直接回到实况 | 单击即可返回，并恢复该会话的视图偏好 |
| 内容 | 会话、搜索、动态 | 打开独立工作页，详情沿用现有地址 |
| 管理 | 用户、账号、审计 | 打开相应管理页，按角色显示可用操作 |
| 账户 | 当前身份、退出 | 各工作页底部使用同一入口 |

实况和分组在窄轨态仍有可读短标签。当前页面所在组有状态标记，展开后当前链接另有选中标记和 `aria-current`。菜单正文从当前组展开，其他组可独立折叠。桌面窄轨取 56 CSS px，抽屉目标宽度 240 CSS px，覆盖内容左侧。选中页面后回到窄轨，`Esc` 收起当前最上层的弹窗或抽屉。窗口较窄时改用带遮罩的抽屉和单列布局，触控目标至少 44 CSS px。菜单打开时将键盘焦点移入，收起时还给触发按钮。选择目的地时将焦点移至新页面标题，前进后退时恢复适当的列表位置或详情标题。

## 内容、权限和路由

- `/admin/` 登录成功且可看实况时进入 `#live`。已有且有权访问的地址优先，终端 F1 的 `#simulation` 转到 `#live/simulation` 并放大模拟窗，`#overview` 转到实况。使用默认入口时用替换历史的方式补齐地址。
- 有权限但无法进入实况时，按现有后台可访问区域的顺序进入第一个可用页面。有明确目标的跳转若对应无权或失效的地址，回到可用页面并说明原因。无可用页面时显示当前登录状态和退出入口。
- 用同一份区域注册表生成菜单与路由，保留服务端逐请求鉴权。隐藏无可用条目的分组。模拟测试继续受现有角色和服务端开关约束。权限被收回或会话失效后，清除原页面的敏感内容并使用对应提示。
- 登录会话内共享现有 SSE 连接。切换页面时销毁旧视图、移除订阅和定时器，并隔离尚未完成的旧请求。按需挂载三维视图。实况返回后恢复图表时间区间、实体上限、场景设置和仍可访问的选中对象。工作页返回时优先保留列表位置及可用筛选，搜索词和内容留在当前登录会话的页面内存。

## 两种工作状态，共用同一套控件

实况主色采用近黑蓝 `#0B1017` 和冷银蓝 `#79C7F2`。场景上方用实色信息带隔开 HUD 与绘制区域，顶部依次排列连接状态、在线用户、活跃频道和近一分钟活动量。连接状态属于后台外框，实况和常规工作页在同一顶部区域显示一次。沿用按消息长度由冷向暖的视觉编码。底边的场景控制与活动日志采用等高等宽的卡片，中间留给可配置时间区间的活动曲线。窄屏下由场景向下排列各面板。文字与数据状态始终有可见标签，连接中断时指明上次更新时间。

常规工作页使用石墨灰框架 `#11151B`、哑光工作面 `#181E26` 和高对比文字 `#E7EDF4`。表面以一层细亮边和一层短阴影表达层次，表格用行距、数字对齐和细分隔线组织信息。工具栏保留一个当前最重要的动作，其余动作放在相关对象旁边。正文、表单框和列表都复用稳定的布局，滚动时关键列头或详情标题可保持可见。

把拟物做在需要操作的位置。主按钮有浅斜面和底部支撑边，按下时下移约 1 CSS px，完成请求后就地显示结果。输入框像压入面板的槽，聚焦时边缘清晰亮起。成对开关的文字随状态更新。危险操作用明确的动作名和既有确认流程，普通用户删除保留确认，模拟账号清理继续采用独立的快速操作，并展示进度和失败结果。

| 工作页 | 优先改善的操作 |
|---|---|
| 会话、搜索 | 固定筛选位置，查询结果与当前详情保持清晰对应，返回结果延续浏览位置 |
| 动态 | 让正文、评论与对应操作紧贴，避免点错对象 |
| 用户、账号 | 列表先用于定位，详情集中显示身份、状态、权限与可操作项 |
| 审计 | 优先呈现时间、操作者、动作和对象，筛选状态常驻 |

## 动效与实时性

- 抽屉平移与高光边缘动效目标 180–220 毫秒。切页外框扫光与正文淡入目标 140–200 毫秒，页面加载、键盘输入和取消操作均可即时响应。连续切页以最终地址为准。
- 三维画布维持独立视口，导航动效仅影响覆盖层。抽屉打开时暂停被遮挡区域的场景拾取，收起后恢复。顶部信息和底部卡片的更新独立于 WebGL 绘制。
- 实时曲线沿用每秒采样，日志保留毫秒时间，活动动画随事件触发。连接、加载、执行、完成和失败各自对应实际状态，并通过文字或形状表达。这一套状态反馈让控制台表现得像一位随时给出反馈的操作搭档。
- `prefers-reduced-motion` 下即时切换菜单和页面，使用明确的静态选中反馈。实况继续按既有动效设置呈现，运营数据、图表更新和日志保持可读。

## 分页和实况中的模拟操作

- 用户列表与会话消息依据可用高度调整请求的页大小。消息以「更早」和「更新」翻页，历史页保持位置，实时消息更新最新页。窗口改变导致页边界移动时，用户列表从第一页加载、会话回到最新页。
- 会话目录与账号列表使用服务端游标和全量数据上的名称筛选。会话首屏的实时刷新最多每 1.2 秒触发一次，历史目录页不会被新流量重新排序。搜索结果、动态和审计替换当前页，浏览记录不会累积成整页长列表。
- 模拟账号网格的列数跟随内容宽度，行数跟随可用高度。每个账号是一个可按下的多选按钮，跨页和筛选时保留选择，以可见计数显示删除范围。
- 实况右上悬浮窗默认折叠，小窗用于查看状态和启停。点击「放大设置」在同一悬浮窗编辑配置和管理模拟账号，缩小后保留配置，折叠后停止查询。
- 终端模拟总开关通过后台 SSE 通知已连接的浏览器。实况就地显示或隐藏悬浮窗，三维视图保持连续。
- 场景控制、活动曲线和活动日志共享顶部统计栏的边界，外侧卡片保持等宽。场景控制按与活动曲线一致的分类筛选动画，日志和曲线独立。两个实体上限改用紧凑滚轮，拖动时可吸附到附近常用整数刻度，键盘和输入框支持精确调整。

## 验收方式

在 1280 CSS px 桌面和约 390 CSS px 移动视口走查入口、菜单、日志与曲线。在实况高实体数量下记录抽屉展开前后画布尺寸、场景实例和动画帧情况，确认导航可独立操作。使用仅统计、仅内容、仅用户管理及超级管理员账户验证可见性和深链接，覆盖会话失效、连续导航和重连。使用全键盘和减少动态效果模式检查焦点顺序、状态提示和破坏性操作流程。
