# Proposal

## Why

后台目前打开后先展示概览，管理员要再次选择「实况」才能看到正在发生的活动。平铺的顶栏把实况、日常查询和敏感管理操作放在同一层，也占用了实况 HUD 所需的空间。把实时态势放在入口，把管理功能放进随时可展开的侧栏，可以让观察和操作在同一个后台内连贯完成。

## What Changes

- 登录后从 `/admin/` 直达有权访问的「实况」。原有书签直达对应页面，浏览器前进和后退恢复相应位置。仅具备其他权限的账号从其可用功能进入。
- 左侧常驻一条窄轨，点按后展开有文字标签的分组菜单。实况始终可一键返回，内容与管理功能在同一后台框架中打开独立页面，按权限显示。旧概览书签直接进入实况。
- 实况采用深色全景界面。连接状态、核心指标、场景控制、活动曲线和日志在视口中各有固定位置。侧栏展开时保持三维场景连续。
- 工作页使用低对比表面、清晰的表格和表单、带按压反馈的按钮。已授权的操作通过就地状态显示进度和结果，切页用短扫光和淡入提示位置变化。键盘、触屏和减少动态效果模式可以完成同样的操作。
- 用户、会话消息和模拟账号列表按窗口可用空间调整分页。实况中的模拟悬浮窗可收起、缩小和放大。放大时可配置完整模拟并跨页选择模拟账号顺序删除。
- 实况底部面板沿顶部边界对齐。场景效果筛选采用活动曲线的分类，实体上限可用整数吸附滚轮调节。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `admin-console` 统一入口、权限导航、工作页结构和操作反馈。
- `server-live` 实况与后台外框的布局、覆盖层交互及场景生命周期。

## Version

Minor，`6.3.0` → `6.4.0`，在实施时更新版本号和发行说明。

## Impact

- 涉及 `pkg/server/adminweb/` 下的后台外框、路由、工作页样式和实况布局。
- 沿用现有后台 API、权限和终端 F1 的浏览器入口。模拟状态接口支持仅返回状态的查询方式。前端资源继续随服务端分发，支持离线部署。
